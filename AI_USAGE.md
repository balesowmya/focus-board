# AI Usage

## AI tools used

OpenAI Codex was used as a coding assistant in the existing VS Code project.

## Representative prompts

- Build a responsive React task dashboard named FocusBoard.
- Implement CRUD, combined search and filters, dynamic statistics, and LocalStorage persistence.
- Use the supplied dashboard content and sample tasks while preserving the existing component structure.

## AI-assisted implementation areas

Codex assisted with the React components, task state and LocalStorage hook, sample task data, responsive CSS, accessibility labels, and project documentation. The developer should review the implementation before assessment submission.

## Reviewed and corrected suggestion

The initial implementation included generic motivational text for the Focus Notes slides. It was replaced with the three supplied titles and subtitles, plus a task preview driven by the current task data.
